# Release v1.8.0

## Instalador Windows

Arquivo: `Instalador_PainelTribuna_v1.8.0.exe`

## Novidades

- Título da sessão na tela secundária em **uma linha**, com fonte que preenche a largura disponível (sem cortar texto)
- Aba **Customização → Tela secundária** reorganizada (layout, monitor, opções e fundo)
- Opções: **exibir ano** no cabeçalho e **tolerância de 1 min no aparte**
- Marca do sistema: logo `favicon.svg` e ícone do `.exe` atualizados
- Aba **Sobre** com logo e foto do desenvolvedor atualizadas

## Instalação

1. Baixe o `.exe` desta release
2. Execute o instalador (como administrador, se solicitado)
3. Opcional: instale o driver USB CH340 durante a instalação
4. Em **Administração → Customização → Tela secundária**, confira layout e monitor do público
5. Inicie pelo atalho **Painel de Controle Tribuna**
